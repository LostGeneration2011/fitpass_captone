# FitPass Branding (Final)

This folder contains the final approved branding assets for FitPass.

## Final files

- fitpass-logo-option-1.svg: Final horizontal logo
- fitpass-icon-option-1.svg: Final app/icon mark

## Applied in project

- Mobile app icon/adaptive icon/favicon/splash are generated from option 1.
- Admin web uses option 1 icon for favicon and auth/sidebar branding.

## Regeneration

Use this script to regenerate app/admin assets from the final SVG files:

- fitpass-app/scripts/generate-brand-assets.mjs
