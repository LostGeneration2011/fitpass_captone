CHAPTER 1: OVERVIEW OF THE TOPIC  
 1.1.  Ask the question  
As technology continues to evolve, the need for online connection and 
interaction is constantly increasing, especially through chat and community-building 
platforms. However, while current applications are powerful, they still present some 
barriers for new users, such as complex interfaces, lack of initial orientation, and lack 
of control over appropriate content in open communities.  

 
  4  
In addition, many platforms are not optimized for a smooth user experience, 
making it difficult to build an accessible, flexible, and friendly community. Therefore, 
a solution that focuses on user experience is needed.  
The goal of the project is to develop a real-time chat application with strong 
capabilities in user role delegation (Owner, moderator, member), supporting flexible 
community organization, ensuring security factors, being friendly to new users, and 
ensuring appropriate content control.  
 1.2.  Solution  
  
Sociable is designed with outstanding specifications and features:  
• Clear interface, smooth experience (Material Design)  
• Real-time messaging feature  
• Send pictures, videos, files  
• Personal profile management  
• Optimize interface personalization  
• Flexible authorization system: Owner, Moderator, Member  
• Topic-based community recommendation system for new users  
• Bot automatically sends welcome messages, community rules when joining  
• Upload content warning and moderation (planned enhancement)  
The application will be deployed using Flutter, Google's cross-platform framework, which allows for 
the development of a single codebase that runs smoothly across:  
Mobile app: iOS, Android  
Website: Google Chrome, Safari, Firefox  
Desktop: MacOs, Windows (expected to increase)

request in their notification  
Accept or Reject Friend Requests: If accepted, User and Friend become 
friends, opening up DM messaging, voice/video calling capabilities. If 
declined, Request is cancelled.  
Manage Your Friends List: Friends list is updated, User has control over  
 relationships.
